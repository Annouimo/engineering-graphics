# 工程图学研习

《画法几何与机械制图》的交互式习题讲解，以及一套可交给 Agent 复用的制作方法。每个讲解从已知图开始，逐步展示纸面作图过程，最后提供完成图供核对。

## 试读

[求点 K 的三面投影](examples/three-view-projection.html) 是 2024 秋期中第 2 题（1）的示例。从 GitHub 下载 HTML 文件，用浏览器打开即可离线查看。

## 制作自己的讲解

把题目和已知图交给 Agent，请它阅读 [AGENTS.md](AGENTS.md)、[知识点索引](topics.md) 和上面的 HTML 示例。可以这样说：

> 请按 AGENTS.md 制作这道题的离线作图讲解。先从 topics.md 选择适用的课内知识点，再参考示例的版式和步骤交互。图上要看得出从哪里量、沿哪个方向画、取哪个交点。

知识点按作图任务组织，使用时可以对照不同教材。SolidWorks 建模与出图实验见 [ai-solidworks](https://github.com/Annouimo/ai-solidworks)。
